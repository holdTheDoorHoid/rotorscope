Your position

Your phone can’t share its location with this page: browsers only allow that on secure (HTTPS) sites, and the hub can’t offer HTTPS without internet. So the hub uses its own GPS, or a position you type here. A typed position is used whenever the hub’s GPS has no fix.

About

Rotorscope only listens: it never transmits to drones. It shows drones that broadcast Remote ID, which is public by design. There is no map view here, because the hub’s Wi-Fi has no internet; each drone’s details have an “Open in maps app” button, which works with offline maps.
