Your position

    

    
Your phone can’t share its location with this page: browsers only allow that on secure (HTTPS) sites, and the hub can’t offer HTTPS without internet. So the hub uses its own GPS, or a position you type here. A typed position is used whenever the hub’s GPS has no fix.

    
    
    
Decimal degrees; south and west are negative. Pasting from a maps app works.

Threat profile

    

    
A profile sets how the hub weighs what drones do. Choosing one here only makes the line for the hub’s site file; nothing is sent to the hub.

    

      
      
      
      
      
    

    

    

      

      

      
Add it to the end of ROTORSCP/SITE.TXT on the hub’s SD card, or type it on the hub’s console (L). A crowd line in the file wins over the profile’s “several at once”. No profile ever lowers: heading straight for you, fast inbound, a striker after a spotter, a new identity mid-flight, or drones during jamming.

About

    
Rotorscope only listens: it never transmits to drones. It shows drones that broadcast Remote ID, which is public by design. There is no map view here, because the hub’s Wi-Fi has no internet; each drone’s details have an “Open in maps app” button, which works with offline maps.
